# Arthuween 2026 — Registro de Campo

## O projeto

O Arthuween 2026 reuniu:

- Lightning Engine;
- Maria Joaquina;
- projeções sobrenaturais;
- escuridão e controle do ambiente;
- comportamento procedural.

## Resultado

Maria Joaquina fez muito sucesso.

O Lightning Engine ultrapassou **25.000 CPM (Caralhos Por Minuto)**, segundo o relato após o evento.

As projeções de fantasmas, zumbis e outros conteúdos sobrenaturais foram exibidas em loop em uma janela voltada para o corredor lateral.

As luzes do corredor foram apagadas deliberadamente para aumentar o contraste e a percepção das projeções.

A composição final foi:

**relâmpagos + caveira + projeções + escuridão + surpresa.**

## O que foi validado

### Lightning Engine

- tempestade procedural autônoma;
- propagação;
- ramificação;
- múltiplos picos;
- curvas de intensidade;
- controle de potência;
- operação prolongada;
- instalação em ambiente real.

### Maria Joaquina

- dois GC9A01 funcionando simultaneamente;
- geração procedural dos olhos;
- movimento suave;
- estado NUMB/LIFELESS;
- comportamento autônomo;
- instalação cenográfica.

## Regra de versionamento

Uma versão congelada não deve ser modificada diretamente.

Alterações futuras devem gerar uma nova versão.

A sequência de desenvolvimento adotada foi:

`POC → teste visual → validação técnica → montagem → evento real → reação humana → validação da experiência`
